# NEXUS — Training System

## Descripción del proyecto

NEXUS es un proyecto académico desarrollado en C# para Programación II. Es una aplicación de consola inspirada en la exploración de realidades. Permite registrar los datos de un cadete, comprobar si cumple los requisitos de conexión y realizar operaciones desde un menú.

El proyecto utiliza clases, objetos, constructores, campos, propiedades, métodos, condiciones, ciclos y un arreglo para guardar las realidades disponibles.

## Objetivo

Comprender cómo se organiza una aplicación de C# mediante clases y objetos y utilizar el propio proyecto para repasar los temas de Programación II.

## Estructura del proyecto

- NEXUS/Nexus/Nexus/Program.cs: contiene las clases principales y la lógica del programa.
- NEXUS/Nexus/Nexus/Nexus.csproj: contiene la configuración del proyecto.
- Manual Técnico de Programación II/: contiene las seis secciones de estudio para el examen H3.

## Manual técnico para el H3

El manual está dividido en seis secciones: arquitectura y programación orientada a objetos; fundamentos de clases y objetos; herencia, polimorfismo e interfaces; colecciones y LINQ; análisis del funcionamiento; y un banco de exactamente diez preguntas de repaso.

[Consultar el índice del manual técnico](Manual%20T%C3%A9cnico%20de%20Programaci%C3%B3n%20II/README.md).

Los conceptos que no aparecen implementados directamente en el código se explican como materia de estudio y se diferencian de las funciones que sí tiene el proyecto.
