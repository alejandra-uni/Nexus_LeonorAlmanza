# Manual Técnico de Programación II

Material de estudio del proyecto NEXUS para preparar el examen del Hito 3.

## Secciones

1. [Arquitectura y programación orientada a objetos](01_Arquitectura_y_POO/README.md): propósito del sistema, responsabilidades de las clases y autorización de conexión.
2. [Fundamentos de clases y objetos](02_Fundamentos_Clases_y_Objetos/README.md): clases, objetos, campos, propiedades, métodos, constructores y acceso.
3. [Herencia, polimorfismo e interfaces](03_Herencia_Polimorfismo_Interfaces/README.md): conceptos explicados como materia de estudio, diferenciados del código actual.
4. [Colecciones y LINQ](04_Colecciones_y_LINQ/README.md): arreglos, listas, filtros, selección y ordenamiento.
5. [Análisis del funcionamiento](05_Analisis_y_Flujo/README.md): autorización, seguimiento de valores, predicción y modificación de condiciones.
6. [Banco de preguntas para el examen](06_Banco_Preguntas_Examen/README.md): exactamente diez preguntas con respuestas razonadas.

## Código de referencia

El archivo principal es NEXUS/Nexus/Nexus/Program.cs. Las clases principales revisadas son Cadete, SistemaNexus y Nexus. Los temas que no están implementados directamente se presentan como ejemplos de estudio y no como funciones existentes del programa.
