# Manual Técnico de Programación II

Material de estudio del proyecto NEXUS para preparar el examen del Hito 3.

## Secciones

1. [Arquitectura y programación orientada a objetos](01_Arquitectura_y_POO/README.md): propósito del sistema, clases y relación entre componentes.
2. [Fundamentos de clases y objetos](02_Fundamentos_Clases_y_Objetos/README.md): instancias, campos, propiedades, métodos, constructores y acceso.
3. [Herencia, polimorfismo e interfaces](03_Herencia_Polimorfismo_Interfaces/README.md): conceptos explicados con ejemplos complementarios, diferenciados del código publicado.
4. [Colecciones y LINQ](04_Colecciones_y_LINQ/README.md): arreglos, listas, filtros, selección y ordenamiento.
5. [Análisis y flujo del programa](05_Analisis_y_Flujo/README.md): autorización, seguimiento de valores y análisis de cambios.
6. [Banco de preguntas para el examen](06_Banco_Preguntas_Examen/README.md): preguntas y respuestas razonadas.

## Código de referencia

El archivo principal del proyecto es `NEXUS/Nexus/Nexus/Program.cs`. En la versión revisada, las clases principales son `Cadete`, `SistemaNexus` y `Nexus`. Los temas que no están implementados directamente se presentan como ejemplos de estudio, no como funciones existentes del programa.
